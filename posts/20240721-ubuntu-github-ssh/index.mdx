## 1. ユーザー情報の登録

まずローカルにインストールした`git`の設定をします。

```bash
git config --global user.name "ユーザー名"
git config --global user.email "メールアドレス"
```

以下のコマンドで登録の確認をします。

```bash
git config --list
```

## 2. SSH 鍵を作成する

1.  生成先ディレクトリ作成

```bash
mkdir -p ~/.ssh
```

2. 鍵生成

```bash
ssh-keygen -t ed25519 -f ~/.ssh/github -C "your_email@example.com"
```

`ssh-keygen`を使用しキーを作成します。

`Enter file in which to save the key`と表示されたら`Enter`を押します。

`Enter passphrase`と表示されたらセキュアなパスフレーズを入力します。

以下コマンドで、`github`と`github.pub`が生成されていることを確認

```bash
ls ~/.ssh
```

- `-t ed25519`
  現在推奨されている安全な鍵方式

- `-f ~/.ssh/github`
  鍵の生成先

- `-C`
  鍵のコメント。識別しやすくするため。

## 3. 公開鍵を GitHub に登録

GitHub の右上のアイコンをクリックし、「Settings」ページに遷移します。
その後左メニューに「SSH and GPG keys」があるのでクリックします。
すると「New SSH key」ボタンがあるのでクリックします。

![ssh page](/static/ssh-page.avif)

以下画像の画面に遷移後 Title に自分がわかりやすい名前を記入し、key には`github.pub`の内容をすべてコピペします。
「key type」は「Authentication Key」のままで大丈夫です。

![add ssh key](/static/add-ssh-key.avif)

## 4. ssh-agent に追加

バックグラウンドで`ssh-agent`を開始します。

```bash
eval "$(ssh-agent -s)"
```

以下のコマンドで SSH プライベートキーを`ssh-agent`に追加します。

```bash
ssh-add ~/.ssh/id_ed25519
```

## 5. SSH 接続の確認

```bash
ssh -T git@github.com
```

初期実行時は「Are you sure you want to continue connecting」と聞かれるため、「yes」と入力し Enter

以下のように表示されれば成功です。

```bash
Hi ユーザー名 You've successfully authenticated, but GitHub does not provide shell access.
```

## 6. 鍵設定

```bash
touch ~/.ssh/config
```

```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/config
```

```txt title="~/.ssh/config"
Host github
  HostName github.com
  User git
  IdentityFile ~/.ssh/github
  AddKeysToAgent yes
  IdentitiesOnly yes
```

- `Host github`
  SSH のショートカット名

- `HostName github.com`
  接続するホスト名

- `User git`
  GitHub の SSH 接続は常に `git` ユーザー

- `IdentityFile`
  使用する秘密鍵の設定

- `AddKeysToAgent yes`
  鍵を自動で ssh-agent に登録する

- `IdentitiesOnly yes`
  指定した鍵だけを使う

## 7. SSH AGENT永続化

- `keychain`インストール

```bash
sudo apt update
sudo apt install keychain
```

- `.bashrc`に以下を追加

```bash
if command -v keychain >/dev/null 2>&1; then
  eval $(keychain --eval ~/.ssh/github)
fi
```
